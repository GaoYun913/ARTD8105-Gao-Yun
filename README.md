# 岩壁叙事 Petroglyph Narratives

一面可随时改写的史前岩画工坊：把野牛、手印、太阳神等图符放到岩壁上，调整矿物颜料与轮廓，生成狩猎、祭祀、迁徙或星象的叙事画面。

## 本地打开

本项目是静态网页，无需构建。

```bash
python3 -m http.server 8080
```

浏览器访问 `http://localhost:8080`。

## 怎么用

- **图符库**：点选图符后点击岩壁放置，或直接拖到岩壁上。
- **颜色**：赤铁矿、赭石、木炭、锰黑、高岭土等矿物颜料，也可自定义。
- **形状**：大小、横向/纵向拉伸、旋转、倾斜、膨胀、粗糙、圆润、线宽，滑杆即时生效。
- **画法**：涂绘、剪影、勾线、线刻、喷绘（适合手印）。
- **叙事模板**：底部一键生成完整画面，生成后仍可继续改每一个形。
- **涂绘工具**：在岩壁上直接画痕迹、矛线或连接关系。
- **导出画面**：把当前岩壁存成 PNG。

快捷键：`Delete` 删除，`Ctrl+Z` 撤销，`Ctrl+D` 复制，`F` 翻转，空格拖动画布，滚轮缩放。

图符造型参考拉斯科、阿尔塔米拉、贺兰山与阴山岩画的视觉语言，均为重新绘制的轮廓，不是遗址照片的描摹。
